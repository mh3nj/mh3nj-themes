IV. Installation

Three steps. No marketplace.

This collection lives on GitHub. Installation is manual.

01 / DOWNLOAD

Grab the VSIX

Head to the Releases page and download the latest .vsix file.

02 / INSTALL

Install from VSIX

Open VS Code, go to Extensions, click the ... menu, and choose Install from VSIX.

03 / CHOOSE

Pick a theme

Open the Command Palette, run Preferences: Color Theme, and pick any of the thirty-four variants.

FROM SOURCE

Or build it yourself

If you prefer to package from source, the repo is one command away. 

git clone https://github.com/mh3nj/mh3nj-themes.git
cd mh3nj-themes
npm install
npx @vscode/vsce package
